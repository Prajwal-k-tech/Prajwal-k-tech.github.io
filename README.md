# Prajwal Kumar K · Portfolio

Personal portfolio hosted on [GitHub Pages](https://prajwal-k-tech.github.io/). It is a static HTML/CSS site with a small script that refreshes the Codeforces rating when the public API responds.

## Local preview

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Open <http://127.0.0.1:4173>.

## Editing

- `index.html` contains the page copy, project order and links.
- `styles.css` contains the responsive layout and visual styles.
- `profiles.js` updates the Codeforces rating and peak, with the values in the HTML as a fallback.
- `assets/` contains the portrait, project images, fonts and downloadable resume.

The portfolio uses a restrained Ristretto palette, self-hosted Geist fonts and project screenshots. PokeForge is labeled in progress; project descriptions distinguish prototypes and team work from completed products. Keep those status and attribution details accurate when editing.
